# 模型设计器交互演示

## 通用研究方案设计

2026-11-11。工作区从研究问题和变量开始。变量可独立添加为候选因子或目标，目标可有多项。观测表显式选择采集列，采样间隔、最低记录数和单位数属于观测要求。日期作为观测表的对齐字段。按天数拟合时，天数才作为一个数值变量绑定到模型。变量和采集要求由方案字节预算约束，不另设固定数量。

画布从采用目录添加任意已登记的组件版本，读取准确的输入、输出和请求 Schema。组件的配置输入按节点独立创建，允许复用同一观测表并连接相容的上游成果。成果以端口声明为准。逻辑斯蒂样例继续保留准确版本、日期评价和演示曲线。新方案的目标来自研究变量，不继承样例的固定评价阈值。

参数表单以请求 Schema 为来源。新组件用 `x-research-variables` 声明某字段引用的观测端口、允许的变量角色及单选或数组形态。服务端核对引用、角色、观测列和评价目标，组件执行入口独立核对请求、数据完整性及计算资格。已有逻辑斯蒂合同保持原摘要，由兼容的呈现注解显示字段中文名称和变量选择器。

第二个参考组件是独立的多变量线性回归。按日期截点分开训练和预测，允许一个或多个数值目标。每行同一地块种植季的候选因子按业务日期对齐。训练成果包含模型系数，预测成果逐日期和目标给出数值。拒绝缺列、重复行、样本不足及设计矩阵秩不足。由独立文件协议运行并检查摘要。它用于验证从组件目录到参数与成果的通用路径，不表示该算法已用实测农业数据验证。

验收从空白建立株高和叶面积两个目标，绑定 NDVI、土壤水分和气温作为输入。核对组件显示预测表和模型成果，导出并重新导入，校验目标和参数引用。用合成观测独立验证单目标和双目标计算及应拒绝输入。通过历史 V3/V4 回归、空库及既有独立库迁移和 249 浏览器复查后发布。正式研究运行继续由已授权的采集和调度链路提供。

## 首版逻辑斯蒂原型记录

2026-11-11。入口为 `/designer/`。首个演示使用逻辑斯蒂生长曲线，帮助研究人员从变量、参数和连线看懂一份可校验的株高拟合方案。

## 界面与交互

- 采用青灰背景、深绿主操作和浅琥珀成果节点。画布展示两路输入汇入模型、模型分出两路成果的结构。三栏为组件与变量、方案画布、属性面板，窄屏按纵向排列。
- 组件目录使用版本化 API，属性面板使用准确组件的请求 Schema。选择画布节点可查看来源、参数或成果。支持修改方案名称、变量绑定和拟合参数，校验问题指向对应节点及字段。
- 可导入带摘要的 JSON 方案或草稿，编辑后导出经服务生成摘要的草稿。演示支持单节点逻辑斯蒂拟合方案，历史版本保留准确合同和版本标识。
- 默认打开空白方案，显式载入时才打开已搭好的逻辑斯蒂样例。用户从资源库添加观测表、拟合设置、逻辑斯蒂组件和所需成果，点击数据或配置节点的输出端口，再点击模型输入端口完成连线。属性面板可以查看、调整或断开连线。未完成的画布仍可保存为草稿。
- 页面直接显示「编辑方案」和「保存到浏览器」。可改方案信息、增改数值观测变量、调整观测表列、修改模型参数及保留的输出。画布节点可拖动，位置作为布局字段和草稿一起保存。浏览器保存使用已有校验接口生成的草稿信封，刷新时校验摘要并恢复。新建和载入样例切换工作区，保留已保存草稿供再次打开。
- 下方图表使用独立逻辑斯蒂组件预先计算的合成样例，显示观测点、拟合曲线和参数。交互查看示例时保持原始样例标记。演示的实际操作到设计校验为止，正式计算走研究运行和调度。

## 接口与代码

`modarchitect/designer.py` 负责演示入口、文件体积和格式校验。两个无状态接口复用研究配置的校验、导入和摘要逻辑。浏览器不持有业务 Key，私有草稿与发布继续使用原授权入口。演示 POST 只消费有体积上限的 JSON，返回配置和检查结果。

`modarchitect/web/designer/` 随应用制品发布。页面结构与样式、交互状态、可视化分别独立维护。图上的连线取自方案，成果曲线使用附带的固定数据。

## 验收

1. 打开演示，新浏览器显示空白画布和 V4 组件。主动载入样例后核对两个输入和两个输出。
2. 切换时间轴制造单位不匹配，后端校验定位失败字段。恢复默认后通过，导出并重新导入草稿保留版本和摘要。
3. 抽查 390 像素窄屏布局、键盘可达性和实际浏览器行为。确认静态资源进入 wheel，现有服务健康检查与授权契约通过回归。
4. 从空白方案添加观测表、设置和逻辑斯蒂模型，通过画布端口连接输入，再选择成果。修改名称，新增观测变量并绑定为目标，关闭、恢复输出，拖动节点。通过校验后保存并刷新，核对方案、绑定、输出和布局都已恢复。

## 结果

- 独立逻辑斯蒂 wheel 通过数值协议拟合 11 个合成观测并对 101 个日期点求值。样例结果的饱和值为 100.02 cm，速率为 0.101 / 天，拐点为 49.91 天，样本内 RMSE 为 1.01 cm。图表和参数从同一份 `example.json` 读取。
- 本机独立 PostgreSQL 验收执行 `python -m pytest -q`，9 项通过。Ruff 和本次 5 个自有 Python 文件的文件头检查通过。安装后的容器响应 HTML、脚本、样式和样例文件。
- Chrome 浏览器验证五个画布节点、时间轴单位冲突与恢复、画布缩放、键盘选择变量、JSON 导出和再导入、V3 版本保留以及 390 像素布局。 [249 演示](http://192.168.3.249:18925/designer/) · [249 发布记录](deployments/modarchitect-249/README.md#设计器演示更新)
