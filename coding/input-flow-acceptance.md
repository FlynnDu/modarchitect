# 输入清单与评价分支验收

2026-11-12。依据用户关于“1 项输入与多个指标不一致”“卡片应列内容”和“数据集到验证分支”的反馈完成修正。

## 实际变化

- 输入卡片与配置表共用 `modeling.js` 的 `inputUsageRows`，避免分别计数。表、指标、记录三个口径分开；上游派生量不重复算为外部输入。
- 联合预测方案列出 5 个外部指标及单位，另标 1 张观测表、90 条记录。后续预测显示所需 4 项已知输入，训练标签不作为预测必填。
- 默认卡片直接显示具体指标、方法参数、样本范围和结果。去掉重复的“研究概况”和每张卡片的通用建议，来源政策与适用范围收在明细中。
- 数据集到时间留出评价显示虚线，预测成果从主线进入同一评价。默认记录分为历史拟合 45、回归训练 25、时间留出 20。统计复用 `dataPeriods`，不从日期跨度补造缺测记录。
- 当前提交记录与运行身份关联供页面显示；查看其他历史运行时只使用已存统计，不能用后来编辑的数据替代原运行。没有留出或正在预测时不沿用训练分支。

## 验证结果

1. **26 项前端测试通过**。包含 16 个研究主题、共享指标清单、增删后计数更新、指标去重、预测阶段输入、无留出/原生资料不画分支、历史缺统计不补造分段、既有模型关系与页面行为回归。
2. **249 实际页面与 HTTP 验收通过**：预览不保存，采用、保存、日期调整及重开一致。将训练截止日改为 06-08 后留出 21 条，保存重开仍为 21；恢复 06-09 后留出 20 条。
3. **3 个真实工作流通过**：气象研究 146、串联训练 147、已有模型预测 148。DolphinScheduler 工作流及任务均为 SUCCESS。串联训练完成 20 条实测配对，模型保存后继续预测，训练状态不变且未重新训练。
4. 页面无 HTTP/脚本错误，卡片与配置表逐项名称一致。当前训练记录显示分支；切换到预测记录显示 4 项输入并移除训练分支；返回训练记录恢复准确统计。
5. 从实际 DOM 留存的组件 HTML 经独立无界面 Chromium 渲染，人工查看了 5 张卡片、逐项清单与虚线布局。该检查是组件渲染检查，完整原生浏览器交互仍未验收。
6. 安装的 **94 个包文件**与 wheel 及工作区一致；**51 个 Python 文件、31 个科学合同文件未改动**。API 请求响应、调度协议和数据库结构保持不变；只更新 API 页面，Worker 与调度服务未替换。
7. 本次修改的一个运维 Python 脚本通过文件头检查与 Ruff。该脚本只增加可选择验收记录及预期实例数的参数，不进入应用 wheel。
