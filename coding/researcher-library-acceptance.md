- 16 个公共研究主题，九个来自勘察能力拆分。表格冠层温度研究的三种方法在方案内选择，另外两种方法不占独立主题卡片。

- 可调整登记的日期、作物或指标，保存重开后按实际参数计算；不能趁改参数更换数据来源或其他科学结构。
- 普通页面不显示旧案例编号、输入封存和制品摘要等技术内容。当前资料明确标记为示例；实测、估计、模拟三类性质不混用。

## 验证结果

- 独立数据库、低权限 HTTP、行为测试 **52 项通过**。本机数据库引擎停止后，在新项目专属 PostgreSQL 实例中新建独立数据库和角色，通过仅监听本机回环地址的短期 SSH 转发验收，未重启用户的本机服务，未使用旧业务库。
- Node 逻辑与 DOM 事件 **21 项通过**，含研究主题拆分、方法选择、简明流程、研究参数进入同一方案及页面术语检查。
- 九个独立子研究在准确科学镜像中全部通过。五类科学负例验证：来源信息缺失保持“无法判断”，冲突天气日期、反向窗口、重复指标日期及布尔数值被拒绝。
- 16 个主题实际保存、重开并由 DolphinScheduler 运行；两种额外方法分别验证；两套训练方案保存模型后完成独立预测。
- 改低温分析截止日和生长分析的日期/指标后实际重算：原输入制品摘要相同，实际输出改变。历史模板继续按原摘要运行。
- 真实页面事件与在线 HTTP 验证：预览不保存，使用后保存，改日期后重开及运行均通过；页面和资源与源文件逐字节核对，HTTP 和页面脚本错误均为零。
- 原双目标页面继续从空白配置、保存、训练、登记模型并预测：覆盖度 0.5、块茎干物质 1600，结果 LAI 2.48、地上生物量 4000，预测不重训。

这一批共 26 个真实工作流（68–93，具体对应以 JSON 为准），工作流与 Shell 任务均为 SUCCESS。页面使用真实 DOM 与在线服务验收，没有替换网络响应；未做原生浏览器像素验收。
