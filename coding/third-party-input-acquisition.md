# 第三方输入取数接入

2026-11-12。首批已实现并部署，7项天气和11项土壤完成真实取数与研究闭环；[验收结果及边界](deployments/modarchitect-249/source-inputs-acceptance.md)。旧项目仅作只读参考。

## 约束与目标

通用边界以[可替换输入来源的架构约定](input-source-architecture.md)为准。本文仅记录天气、土壤首批适配，不另建一套目录、获取、授权或研究封存规则。[一手资料核对](third-party-provider-research.md)区分文档事实、实测及待验收项。

农业科研增强按[输入与组件建议复核](agricultural-input-design-review.md)一并落实：补足实际时空支撑、土层/统计方法、记录可用时间和质量证据；保留已有节点用途。元数据先进入快照及运行来源清单，向旧组件投影时保持准确表形态，不直接向旧表添加字段。

接通既定的 7 项天气与 11 项土壤来源，服务端取得原始资料、按准确方法形成标准记录和不可变快照。研究采用快照；上传同名数值不能取得第三方资格。不修改已冻结来源合同，不通过更改一个 available 标志宣称接通。

## 首批准确来源

土壤仅使用 SoilGrids **WCS 2.0.1**，不实现或回退到已暂停的 REST。准确属性、土层、mean 由来源合同限定。使用原生 IGH 投影的 250m 单像元，校验实际 CRS、shape、transform、图层身份与覆盖，不以附近像元均值代替参考点。规范单位沿用已有准确转换，不复用旧 CSV 中的混合 d_factor。静态土壤水分参数不能代替每日墒情，按业务日复用也不增加独立样本。

真实小请求发现海域可能返回 0 且没有 NoData 标签；容重为零必须拒绝。其他可能合法为零的属性需要充分的同像元覆盖依据，不能全零当缺测或全零当有效。覆盖门禁未形成可验证规则前保持不可用于正式研究。

天气固定已采用的 Open-Meteo 历史日记录、上海日界、准确字段和转换方法。7 项指标保留网格估计性质；辐射转 kJ/m²、雨量保持 mm、10m 风按准确方法转 2m 风、水汽压按日均露点转换。小时聚合要求完整整点，质量策略由准确方法约束；历史资料缺失不能静默取未来预报，也不能沿旧代码统一“两天延迟”推定所有产品齐全。

旧 TEMP 转换允许带质量标记的同日极值均温回退；首批可采用严格完整小时子集并拒绝缺小时，不在同一准确方法下偷偷产生未登记回退值。是否新增另一种处理方法须明确版本并验收。商业调用资格及凭据由部署提供，不能用旧说明推定当前免费接口适用于任意部署。

## 实施路径

本批最小可验收范围：先交付准确历史解析、异步采集、不可变快照、天气与 WCS 两个适配器，以及快照进入现有地块日值训练/预测的闭环。个人工作区使用自有参考位置，不授予企业地块资格。完整实验管理、样株执行、通用预处理学习和数据同化不在本批伪装实现；来源记录的可用时间未知时明确限制为回溯/给定因素研究。

实现使用 `input_sources/{contracts,service,weather,soil,worker}.py`，`persistence/source_store.py` 及必要的 HTTP 装配；历史来源解析保留在 `system_inputs.py`，快照科学匹配集中在输入来源合同，运行入口仅受权解析引用。新增依赖 rasterio/pyproj 用于真实 GeoTIFF 及原生投影，写入 pyproject.toml。新增采集/投递/快照表在专用验收库 autogenerate 后审查，沿用强制 RLS 与不可变证据约束。

1. 先拆清当前采用与准确历史绑定解析，来源更新不影响旧方案解释。获取注册表按准确来源及实现版本装配，两个提供方不进入研究算法分支。
2. 增加最小获取合同、采集执行资源和不可变快照。采集 API 只引用准确方案修订与授权范围，DolphinScheduler 调度采集 Worker，网络等待不占数据库事务；研究预检始终只读。
3. 分别实现 Open-Meteo 和 SoilGrids WCS 适配器。协议读取、确定性转换与共同来源门禁各有归属。固定端点、限额、超时及有界重试；读取失败不回退另一来源。
4. 保存、预检、训练和预测按受信主体解析快照引用，统一校验准确绑定、对象、日期、值性质及单位。模型保留训练来源，预测使用新的当次快照。
5. 先在专用隔离库验证迁移、不可变约束、幂等和强制 RLS，再部署 249 独立项目。旧项目、旧库和既有研究记录不参与修改。

接口、模块和通用失败状态按架构约定实施；本文件不再采用最初“同步请求内直接取数并返回观测表”的草案。该草案会把外部耗时、重试和来源资料混入请求生命周期，与统一采集执行边界不符。

## 可观察验收

- 两个适配器通过正常获取入口返回准确标准记录及原始证据；原文可离线重复转换，结果与规范预期一致。
- 天气实测完整日界、小时数、单位、产品与质量；土壤验证 11 项属性、6 个土层、原生像元、准确单位及无效覆盖。未通过项仍阻断，不以少量正例代表全部接通。
- 研究完成来源采用、保存/重开、预检、真实海豚运行、保存模型和新资料预测。工程构造实测标签不等于农业效果验收。
- 缺数、错对象/日期/土层、改名/单位/方法/值、错版本、跨空间引用、授权撤销、并发重放与迟到回传均按规则拒绝或保留准确缺口。
- 更换获取实现不修改算法；追加来源采用版本后旧方案仍准确解析旧来源。保留现有人工、合成演示、指定资料和模型回归。
- 完成相关 Python 行为、文件头、静态及受影响前端检查，记录实际提供方、数据库、部署及调度证据，明确未完成的真实授权与数据质量验证。
