# 研究方案的资料与成果展示

盘点当前目录的 20 个主题和 22 份定义（含方法变体）。其中 10 份使用指定资料包，12 份使用标准观测。标准观测通过已有变量、用途及来源绑定解释。指定资料包的 `collection_requirements` 可以为空，计算成果由 `composition.outputs` 给出。当前页面从扁平的 `input_requirements` 能读到指标说明，但流程图按端口渲染时丢失了这些说明。温室方案有三组输入，现有面积说明也被放在作物系数一侧，原始面积实际来自称重记录。

在 `study_inputs` 中将现有输入说明关联到 `composition.inputs[].code`，只为模板详情的 `input_requirements[]` 增加 `port`。投影依据外部端口、准确组件绑定和模板的公开字段定义。方法参数包、样例目标、观测值与可选证据分别说明。无可公开字段的历史资料仍显示可核对的资料组。模板定义、摘要及现有执行政策沿用原合同。

设计器按准确模板引用判定说明是否适用。资料步骤和流程卡共享按端口归类的说明，给出名称、单位、用途和来源。支持选择示例指标的方案依当前计算设置显示采用的指标。成果列表共用按实际输出端口查询准确组件名称的方式。模板预览可直接访问研究资料和成果。

验收覆盖目录的每份定义和可重开的历史模板。温室三组资料与三个成果逐组匹配，冠层温度显示数据与方法参数、留出实测目标，天气风险及农业指标显示具体变量。普通方案保留已有输入来源及成果。缺乏真实接入的方案仍显示示例资格。

## 模型输入表与示例入口

冠层温度方案将空气温度用于计算，将冠层温度用于训练和留出评价。两项都来自固定合成资料。向导根据已有 `input_requirements` 的字段用途显示只读输入和目标，保留资料组和流程的准确引用。固定资料的字段不参与普通指标库的新增、删除和角色修改。

资料步骤的「查看本方案输入示例」根据当前方案显示指标、单位和用途。当前已载入合成观测时可示例一条对应记录。指定资料只显示公开字段说明。查看动作只在页面打开只读预览，无需重新取数或保存。

通用双目标示例从方案选择页独立打开，明确显示示例主题。该入口先载入一份未保存的新草稿，保存由用户操作触发。验收核对冠层温度输入与目标、当前方案与流程、保存请求数量，以及显式新建后的独立草稿。

`npm test` 通过 121 项。以 `--inventory-only --verify-module-links` 复跑本地 HTTP 与 DOM 验收，22 份方案通过。回读确认查看冠层温度示例期间页面地址、流程图和方案版本一致，查看没有发出 HTTP 请求。独立双目标示例在显式保存后获得新 ID，冠层温度原草稿仍可回读。
