## 使用与复跑

研究人员从系统目录选择人工目标及天气/土壤指标，在“数据来源”载入自有观测、声明参考位置并采集。土壤必须先选土层和 mean；取得资料后保存、检查并运行。第三方估计不能替代实测训练目标。详见[使用说明](../../../docs/research-study-guide.md)。

```powershell
$env:PYTHONPATH = '.'
python scripts/verify_source_research.py --base http://192.168.3.249:18925 --output <研究验收文件>
node scripts/verify_source_ui.mjs
```

提供方单独复跑使用 `scripts/verify_provider_inputs.py --source weather|soil --output <文件>`；土壤用 `--depth` 明确标准层，天气部署须配置科研或订阅接入资格。回归使用项目虚拟环境和新建专属验收库；数据库凭据不写入证据。

## 明确边界

当前工作区采用自有参考位置，首批计算适配为单地块种植季日值，不能冒充企业选地授权、单株或所有时空尺度。土壤是静态网格估计，同一记录展开多日不增加独立样本；无缺失标记的零值保守拒绝，可能需要后续更充分的覆盖依据才能采用合法零值。

历史资料的事前可用时间未知时，只用于回溯或给定因素研究，不能宣称提前7天预报。当前研究部署使用科研接入模式；商业部署须配置相应提供方资格。完整采样证据、试验上下文执行、通用预处理拟合/划分、独立地块验证和不确定性分析按后续准确组件逐步接入，不以本批来源成功宣称已经完成。
