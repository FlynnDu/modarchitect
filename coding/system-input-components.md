## 需求与已核实边界

用户选择系统已经定义的输入指标，决定它在研究中是目标还是因子；不需要自行发明代码、单位或取数来源。四类是人工采集、第三方平台、平台分析记录、物联网输入，区别于计算组件类别、目录绑定种类和上游模型产生的派生变量。

迁移 worktree 的来源词典、变量原始合同、准确来源策略、采样指标合同为依据。Open-Meteo 是当前天气策略，不能自动换 NASA。SoilGrids 必须选择登记的深度与统计量。长势报告覆盖区、采样点局部值与单株实测不可混用；NDVI 五档业务统计不进入研究指标。物联网仪器指标有定义但没有可采用的供应商/设备/点位绑定。未绑定的旧通用特征和温室计算输出不冒充新输入。

15 项人工指标中，4 项地块种植季指标适配现有日观测表；点位株高、单株性状和样方产量需要显式科学单位适配。现有高度/叶面积样例保留为合成演示，不重写成真实目录指标。目录可设计、取数通道已实现和本次数据已就绪分别表达。

## 实现与调用链

1. 独立项目携带一次经过核对的版本化目录制品，保留旧合同、来源策略及源文件摘要。只在本项目登记，不依赖旧系统数据库或运行时文件回退。
2. `system_inputs.py` 负责目录投影、准确绑定、固定定义和来源选择校验。公开目录接口返回四类、可选择条件、固定来源、观测单位、方法、属性 Schema 和实际运行限制。配置接口从准确条目生成变量与采集要求。
3. 新建普通研究从目录选择输入；代码、名称、单位、科学支撑和来源不可编辑。角色与采样频率可以编辑。土壤深度等属性按 Schema 明确选择。上游派生变量单独保留，不列为外部观测，也不要求伪造采集来源。
4. 方案可保存尚未取齐的数据；已绑定定义在检查、保存和发布时一致核验。旧格式仍可原样导入、读回和归档，不因此获得真实数据执行资格。个人工作区保存普通研究、发起新训练时必须使用完整系统输入绑定，合成演示单独标注。企业入口仍可携带旧草稿，但不能绕过真实运行的来源检查。
5. 当前确实实现的取数通道是工作区按标准填写/导入人工记录，服务端冻结上传内容摘要、工作区主体、准确变量/来源定义、属性、方法及对象日期范围。它不是业务系统自动同步。平台分析、第三方和物联网缺少本项目受权取数适配时，运行明确拒绝，禁止用上传列或人工替换。点位等科学支撑缺少适配时也明确拒绝。
6. 训练封存输入来源清单；模型制品保留同一清单，后续预测核验新输入并形成新的清单。已经保存的旧模型继续按原状态推理，来源显示为历史上传，不能改写既有训练证据。

本次实际目录为 63 项：人工 15、第三方 18、平台分析 21、物联网 9。有准确绑定可用于设计的 33 项；当前工作区已实现记录通道的是 `lai`、`agb_kg_ha`、`tuber_dm_kg_ha`、`canopy_cover` 四项。人工变量本体沿用旧合同，本项目新增的 `system_manual_record@1.0.0 / standard_manual_entry` 只描述标准记录录入通道，不表示已经获得业务系统观测或完成田间测量方法联验。第三方保持原策略方法，未增加替代来源。

复核补充：旧版已排队载荷没有来源清单时，新 Worker 不制造空训练来源；此类模型继续保留历史预测路径。已绑定输入的上传列名也与准确目录核对，防止算法/模型显示另一指标名。新增因子后的观测模板按当前配方重建列，保留已有值、新列留空，并提示补齐；不以缺省数值冒充观测。

```mermaid

  Catalog[版本化系统输入目录] --> Select[选择指标/角色/来源属性]
  Select --> Save[校验准确定义并保存方案]
  Save --> Ready{检查取数通道与科学单位}
  Ready -->|缺适配或授权| Block[列出缺失条件，不回退数据源]
  Ready -->|标准人工记录| Seal[校验数值并冻结来源清单]
  Seal --> Run[真实海豚和隔离 Worker]
  Run --> Model[模型保留来源，继续预测]
```

## 结构和兼容

输入来源规则集中在一个领域模块，路由只解析协议，页面消费服务端配置模板；执行器只把服务端封存的清单写入模型，不重新推断来源。准确旧 `CatalogBinding` 身份和 `CollectionRequirement.source` 枚举不变，不把四类展示类别混入旧业务协议。目录制品属于安装包；绑定与完整运行来源证据沿用已有不可变方案/运行/模型 JSON 和摘要保护，无需新增可变数据库表。后续正式接入来源时必须新增受权通道并复验真实数据，不以切换一个 available 标志代替接入。

## 验收

- 目录与原始合同逐项核对；四类计数与不可用原因真实。禁止未知代码、改单位/名称/边界、改来源版本/摘要、改方法、漏选/伪造属性、把估计量作实测目标。
- 普通输入拒绝无绑定变量；合成演示保留。第三方上传冒充、点位改地块均拒绝；缺通道不产生运行。派生变量不误判成外部输入。
- 从正常 HTTP 接口完成标准人工多变量方案保存、重开、运行、保存模型、预测及工作区隔离；核对运行与模型来源清单及内容摘要。保留原多变量/串联演示回归。
- 页面测试实际点击目录、选属性、加入方案、查看固定信息，普通输入无自定义编辑入口。浏览器视觉、真实企业授权及外部提供方联验如未完成单列，不把替身结果写成业务接通。
- 使用项目虚拟环境运行相关 Python/JS 行为测试及全部本次 Python 文件头检查，构建安装包后在 249 独立服务验证。
