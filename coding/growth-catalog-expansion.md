# 作物生长研究目录扩展

2026-11-20。在 v0.4.0 的 8 套公开方案基础上新增 12 套，使研究目录达到 20 套。每套明确可核对的研究问题、预测前已知条件、独立实测目标、验证范围及可复用的成果。沿用地块、作物、种植季及业务日合同。

| 新方案 | 条件与目标 | 默认方法及适用范围 |
| --- | --- | --- |
| 冠层覆盖扩展曲线 | 观测日期 → 冠层覆盖度 | 逻辑斯蒂增长段，适于从扩展到趋稳的观测。避开已衰退阶段。 |
| 块茎干物质积累曲线 | 观测日期 → 块茎干物质 | 逻辑斯蒂增长段，限具有连续块茎膨大记录的作物与种植季。 |
| 从冠层覆盖度估测叶面积指数 | 同日冠层覆盖度 → 叶面积指数 | 小样本高斯过程，给只有冠层观测的业务日做估测，用实测 LAI 验证。 |
| 冠层与叶面积估测地上生物量 | 冠层覆盖度、叶面积指数 → 地上生物量 | 随机森林，在有同期表型而缺少当天破坏性取样时估测。 |
| 地上长势估测块茎干物质 | 叶面积指数、地上生物量 → 块茎干物质 | 多变量线性基线，比较同一作物和生长阶段内地上、地下指标的关联。 |
| 日最低最高气温与冠层覆盖度 | 日最低与最高气温、太阳辐射 → 冠层覆盖度 | 多变量线性回归，用日极值对照冠层覆盖。 |
| 气温与辐射下的叶面积指数基线 | 日平均气温、太阳辐射 → 叶面积指数 | 多变量线性回归，作为仅用气象的对照基线。 |
| 降水与土壤持水特性下的地上生物量 | 日降水、土壤 33 kPa 含水量参考、太阳辐射 → 地上生物量 | XGBoost，比较不同土壤和天气条件；土壤参考含水量代表规定压力条件。 |
| 风速与水汽压条件下的冠层覆盖度 | 2 米平均风速、水汽压、日均温 → 冠层覆盖度 | 多变量线性回归，用同日气象判断观测条件下的关联。 |
| 土壤 pH、阳离子交换量与块茎干物质 | 土壤 pH、阳离子交换量、日均温、降水 → 块茎干物质 | 多变量线性回归，需多地块独立土壤差异才能评价。 |
| 土壤粗颗粒与容重下的冠层覆盖度 | 土壤粗颗粒体积分数、容重、降水、太阳辐射 → 冠层覆盖度 | 多变量线性回归，以现有土壤参考资料及实测冠层验证。 |
| 卫星植被指数估测冠层覆盖度 | 合格影像的红光和近红外、土壤与气象 → 实测冠层覆盖度 | 平台先计算 NDVI 并配对，再训练随机森林。只在合格过境日估测。 |

数据定义存放在独立版本化目录文件中，与已有模板共用 `study_templates` 的摘要校验、目录资格、默认详情和按摘要回读。每个新定义复用已登记的来源、端口、模型修订与运行槽位。线性、树模型、核模型共享同一份对外资源、配置和评价结构。现有 25 条定义及历史归档保留各自准确摘要。

日期较早的记录用于训练，较晚的实测用于验证。表型当日估测在预测时仍需当天已知的因素；跨地块、跨季节推广和提前量另需独立验证。土壤网格参考、气象估计、卫星反射率分别保留来源。两个论文方案所需的单株影像和小时称重适配仍另行验收。

验收通过两个目录入口核对 20 套及历史摘要。12 套新增方案分别通过配置检查、保存、发布、回读、训练、留出评价、保存模型及独立预测。合成数据只用于验证计算和接口，实际取数及数据覆盖按研究实例核验。

隔离 PostgreSQL 回归 201 项通过，前端回归 144 项通过，修改的 7 个 Python 文件通过文件头与 Ruff 检查。安装包中的真实浏览器验收核对 20 张卡片、遥感主题筛选、卫星冠层覆盖度方案的资料与配置，以及从页面保存为可应用版本。

读取生物所 v0.4.0 的方法目录时，多变量线性、随机森林、XGBoost 和高斯过程返回可运行，逻辑斯蒂生长曲线返回可设计。新增的两套日期曲线已用真实算法在隔离环境通过训练和预测。生物所实际运行这类方案需登记对应训练及推理制品。

## 模板图标

每套公开方案配置一个 1024 × 1024 的 SVG，文件名采用 `{template_id}.svg`。图形采用参考色板中的单色填充与闭合路径，轮廓以完整实心形状为主，用局部留白表达细节。卡片按 24 × 24 显示。工作区和业务 API 的模板列表及详情通过同一投影返回可选的 `icon_name`。安装包包含 `designer/study-icons/` 的静态文件。图标从文件名约定解析，独立于科学定义及历史摘要。前端把图标视为装饰，卡片标题提供可读名称。缺少图标的历史条目使用通用图标。交付时附上文件与方案名称的对应清单。

验收核对两个 API 的列表与详情、20 个 SVG 的静态响应、安装包资源和真实浏览器的图标加载。方法选择回归核对在只有一个训练模型时保留实际的卫星配对绑定，并从标题和弹窗分别呈现。
