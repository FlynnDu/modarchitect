# 研究方案运行与模型预测闭环

2026-11-11。按已复审架构交付多变量研究和串联研究，两份方案均能在 249 保存、重开、执行、保存训练模型并进行后续预测。

## 目标与验收

- 多变量方案用天数、NDVI、土壤水分、气温同时预测株高和叶面积。串联方案用历史逻辑斯蒂预测、显式合并和多变量回归验证实际文件成果传递。
- 浏览器能云端保存和重新打开方案，上传数值观测、启动、查看真实运行状态与结果，将成功成果保存为准确模型，再输入新因子进行预测。
- 先提供明确标注的合成演示数据及独立已知答案，同时支持自有 JSON 观测输入。真实农业精度由独立采样验证。训练按截止日封存，留出标签只用于评价。
- 重复启动复用首次运行，跨工作区不能读取他人方案、运行和模型。模型预测复用训练状态，输入可以没有目标标签。验证错误单位、缺少特征、篡改模型和旧执行尝试提交的拒绝行为。

## 现状和复用

复用 `ResearchDesigns` 的草稿及冻结版本，`DesignStore` 的短事务和行级安全、`compile_plan` 的图与语义校验、现有组件文件协议、独立 OCI 制品及隔离执行。研究规则继续共用，既有企业身份 API 保留原协议。当前公开设计器仅本地保存，研究运行、模型资源和独立推理需要新增。

## 职责与接口

`modarchitect/runtime/` 承载运行契约、持久化、应用流程、调度与 Worker 执行。工作区身份及 HTTP 入口与计算分开。页面增加数据、云端方案、运行结果和模型预测操作，复用同一份编辑器配置。

- 工作区使用服务端签名的长期 Cookie 标识个人空间，身份只用于该项目中用户自行提供的观测。服务端复用已有方案保存和发布规则，不向页面提供业务接入密钥。企业地块与点位仍通过原受权业务 API。
- 新表保存运行封存输入、状态、执行尝试、调度关联、成果、准确模型和待调度记录。按资源范围与主体约束读写，方案版本及训练制品均有可追溯引用。
- API 创建运行后返回运行身份。独立调度消费者提交 DolphinScheduler，Worker 领取封存输入后执行。实际调度及回传与科研结果身份分别记录，提交结果未知时保留待对账状态。
- Worker 按服务端登记的准确组件制品执行拓扑，核对输入、调用身份、输出端口和成果摘要。计算离开 API 请求周期。每次恢复有独立尝试，旧尝试失去提交权。
- 新增历史曲线训练成果和推理组件，回归推理复用原系数。训练后的串联模型保存所有必要的上游状态，预测时依次生成历史曲线因子、合并新因子及计算回归结果。

首批任务为按业务日输入的数值估测和留出预测，页面明确输入日期含义。多起报时刻的小时预报和跨地域科学效果沿复审方案另行验收。

## 实施与验证

1. 增加运行与模型合同、存储迁移及受权工作区，验证云端保存、重开和隔离。
2. 扩展独立组件的训练状态与推理合同，正反例验证单模型和串联的后续预测，保留旧组件版本。
3. 接入调度消费者和 Worker，完成封存输入、幂等、结果摘要和故障状态验证。
4. 页面贯通方案、数据、运行和预测，在 249 验收两份方案及重新访问。记录准确制品和调度实例。

使用项目虚拟环境、现有行为测试和专用隔离 PostgreSQL。运行全部修改 Python 文件头检查。249 采用独立研究库的增量迁移，并归档应用回退制品。真实命令、结果和待验证项在本文件及部署记录中补齐。

## 已交付边界

`runtime/contracts.py` 定义上传、运行和模型合同；`service.py` 复用已有研究规则；`store.py` 管理原子保存、封存输入、队列、租约和不可变模型；`scheduler.py` 只负责提交真实海豚实例；`worker.py` 领取及回传；`executor.py` 通用编排拓扑和模型状态；`containers.py` 负责准确制品及文件隔离。身份和 HTTP 协议分别放在 `workspace.py`、`routes.py`。

配置和观测在同一受权事务中保存。只编辑观测也会推进共享修订，旧页面不能覆盖新数据。研究创建用封存摘要重放，草稿后续变化不会改变旧运行。模型发布保留全部训练节点的状态及准确镜像；推理通过注册表声明切换组件，不在编排器中按科学算法名称分支。串联节点传递实际成果字节，并逐边核对 SHA-256。

调度采用本项目独立的 DolphinScheduler 3.4.0 Standalone、JDBC 注册与持久 PostgreSQL 元数据库 `modarchitect_scheduler`。研究库仍为独立项目的 `modarchitect`。海豚元数据库与研究库使用不同登录角色。海豚控制接口只绑定主机回环地址，研究 Worker 只在项目网络内访问。任务工作目录、资源目录、日志和磁盘监控使用 `/mnt/sda1/modarchitect/dolphin/`，负载保护保持启用。
