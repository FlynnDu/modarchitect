# 土壤、气象与卫星联合研究的接入设计

2026-11-13。实施前约定；以用户提供的海豚环境配置及 mlgrowth 只读代码证据为依据。旧项目不修改。相关一手核对见[来源复核](sentinel-input-integration-review.md)、[来源架构](input-source-architecture.md)及[日调度合同](daily-research-dolphin-contract.md)。

## 已核实的继承与部署差异

- 旧 `api/config.py` 从 `MLGROWTH_DS_ENVIRONMENT_NAME` 读取环境名称；`api/services/dolphin.py` 创建带 `environment_name` 的 Shell，并在启动时采用解析后的 `environment_code`。取数 CLI 由海豚 Worker 本地执行，Shell 进程继承该环境。
- 旧天气的 `dp-meteo` 进入 `pymlgrowth.cli.commands` 再调用 Open-Meteo 同步；土壤 `dp-soilgrids` 进入 SoilGrids 同步。土壤研究应参考 `isric_soilgrids/profile.py` 的 WCS 原生网格和 `research_models/source_normalization.py` 的规范单位。不能恢复已弃用 REST，也不能把旧代码的邻点后备隐入固定参考点合同。
- 旧 Sentinel Hub 认证读取 `SH_CLIENT_ID`、`SH_CLIENT_SECRET`、`SH_BASE_URL`、`SH_TOKEN_URL`、`SH_PROFILE`。新接入仅使用显式环境配置，不回退开发机个人 profile。
- 当前项目为海豚 Shell → 独立 HTTP Worker → 领取封存来源任务。海豚环境不会自动进入该 Worker 容器；仅把 environmentCode 配上会产生“配置存在、执行取不到账户”的实际缺口。

完整文件、行号及未核实项由来源复核记录提供；“参考旧项目”不等于复制旧数据库连接、旧目录或过期端点。

## 配置与凭据边界

1. 环境名称通过部署变量采用，当前部署值为用户约定的 `sumfen-mlgrowth`；程序按名称解析真实 environmentCode，不固定数字、不默认采用第一个环境。来源工作流和执行器采用同一准确引用。缺环境或权限时明确拒绝。
2. 账户、可变端点和运行路径来自环境或已登记提供方配置；研究表单和研究输入不接收这些信息。科学指标、波段、单位、质量方法及算法版本通过版本化合同明确，不用环境变量改写科学定义。
3. 为保留独立 Worker 边界，采用旧 `api/services/dolphin_environments.py` 已有的只读精确名称解析方式：Worker 的基础设施凭据提供器从同一海豚环境读取配置，只解析白名单环境项为本次不可变设置，再显式注入来源客户端。禁止执行 `export` 脚本、修改全局 `os.environ` 或经 HTTP 业务参数传密钥。环境每次采集重新解析，读取失败不回退旧账户。凭据不进入启动参数、封存输入、来源证据、结果、公开 API 或日志；旧 PostgreSQL、OSS、业务 API 配置不进入来源设置。
4. 环境读取/传递与来源适配器分离；天气、土壤、卫星分别消费自己的设置。更换提供方或科学产品通过准确来源版本采用，不以任意 URL 或临时账号串覆盖合同。

## 联合研究与数学关系

新增研究：**土壤、气象与卫星植被指数联合预测**。土壤采用准确土层的静态网格参考；气象采用上海业务日的准确日值；卫星采用 Sentinel-2 L2A 的明确原生参考像元与实际过境时间。预测目标采用系统已有的人工实测叶面积指数；三类因素与训练目标分开说明。

`NDVI = (近红外反射率 − 红光反射率) / (近红外反射率 + 红光反射率)` 是显式计算节点。来源适配器获取红光、近红外及原始质量与场景证据；不把影像分析伪装成现成实测。派生 NDVI 进入后续回归因素，不能作为人工观测标签。

卫星不是逐日必有：按 Catalog 的真实采集时间选择准确场景，Process 取 REFLECTANCE/FLOAT32；光学B04/B08原生10m、SCL原生20m，按声明的10m UTM对齐请求网格参考采样，不能冒充整个地块的均值或所有信息的原生10m像元。质量采用明确最近邻方法。整瓦片云量不能替代参考像元质量。保留 dataMask、SCL、实际场景标识与服务版本；无清晰观测不补零、不前向填充、不伪造每日新影像。若合成多个采集时间而无法说明实际场景则拒绝。

标准输入必须明确稀疏场景日期与完整每日天气的区别。装配只在研究要求且实际有合格卫星观测的对象日期配对；因缺数而缩小训练样本必须有明确结果，不可静默换地块、日期、土层或影像。每日批次没有可用场景时保留缺口；非逐日采样与回溯研究按其准确输入规则处理。

## 最小验收

- 对照旧项目代码证明三类来源、认证与海豚环境的实际调用链，环境内容或凭据不输出。
- 不启动外部依赖的来源正反例：OAuth失败、过期、错误端点、错场景、错日界、云/阴影/无数据、无清晰影像、重复及越权引用；并发请求的账户设置不互相污染。
- 通过真实海豚工作流证明指定环境进入实际获取客户端；研究保存、重开、场景配对、明确NDVI节点、训练、模型复用与新资料预测分别留证。工程标签与农业精度分开验收。
- 原土壤和天气方案、旧准确模型及来源快照继续解释；所有新准确组件有统一清单、独立文件协议正反例及固定制品。
