# 模型成果连接

## 设计与使用

使用现有版本化组件端口和方案拓扑。用户在画布上选择模型输出，再连接类型相符的下游输入。发布校验同时核对已知表列、实测目标和组件要求，按依赖顺序处理；运行时按冻结制品与输入摘要复核。

本批提供“历史逻辑斯蒂预测 → 按对象日期合并预测因子 → 多变量线性回归”的可运行参考。两个新节点独立交付，原逻辑斯蒂 V4 与回归 V1 的冻结合同保持原样。原 V4 曲线的列可以推导，已知缺列或预测值冒充实测标签时拒绝方案。

| 节点 | 输入 | 成果 |
| --- | --- | --- |
| 历史逻辑斯蒂预测 | 同一张观测表，天数列、实测目标列和基线训练截止日期 | 截止日期之后的预测特征表，含对象、日期、预测列、上游摘要和训练截止日期 |
| 合并预测因子 | 实测表和预测特征表 | 同一对象与日期严格匹配的数值表，保留实测列，给预测特征分配显式的独立列代码 |
| 多变量线性回归 | 合并表、输入因子、实测预测目标、回归训练截止日期 | 训练后的模型和预测结果表 |

外部输入不申报预测特征列为实测。设计器从研究变量选择一个数值协变量作为合并后的新列，服务端按数据流核对已知可用列。上游以地块、作物、种植季分组，只用基线截止日及之前的实测值拟合。合并以日期范围和完整对象键进行，保留基线截止日之后的所有实测行，缺配、重复、列冲突或未来数据截点立即拒绝。回归训练截止日必须晚于基线截止日。留出日期依然使用当次预测时已知的因子。

页面提供可编辑的串联样例。隔离验收按真实文件协议运行三个组件，前一步的结果清单及摘要直接成为下一步的输入。正式 Worker 接入与实测业务授权单独验收。

### 访客发现与操作

「打开串联样例」放在页面主操作区，`/designer/?example=chain` 可直接打开同一个公开样例。打开样例时保留浏览器中已保存的草稿。组件卡显示可点击的「输入」「输出」及端口名称，画布上方同时列出组件之间实际连通的两端。触屏与键盘可以完成同样的连线。

## 验收

- 合成数据先以较早日期训练逻辑斯蒂，输出预测表，再由合并组件和回归计算留出预测。用已知答案核对每步成果及 SHA-256。
- 拒绝原 V4 曲线直连并丢失实测目标、合并列冲突、不同对象同一天错误配对、缺少预测行和回归截点早于基线。
- 在 249 从样例移除两条上游连接再手动恢复，核对校验、保存与刷新。发布采用独立数据库的新增冻结目录记录。
