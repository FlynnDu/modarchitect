# 作物生长关系与预测研究目录

2026-11-20。研究方案的目标是：采集自有数据，学习候选因素与作物生长指标之间的关系，通过留出观测验证，保存准确模型用于后续预测。

## 新研究必须具备的条件

| 条件 | 用户应得到什么 |
| --- | --- |
| 明确生长目标 | 预测叶面积指数、生物量、冠层覆盖度等具体指标，保留科学单位 |
| 准确候选因素和采集 | 明确实测目标及已知因素的来源、对象、日期和配对规则；可以采用自有数据 |
| 关系训练 | 从因素和实测目标拟合关系；目标不能同时充当自己的输入 |
| 留出验证 | 用未参与训练的观测计算逐目标误差，说明时间或地块验证范围 |
| 可复用模型 | 保存训练状态、因素/目标定义及来源证据，独立预测复用原模型 |
| 可解释的成果 | 查看实际模型关系参数、预测结果和验证误差，沿准确版本追溯 |

不同单位的回归系数不能直接比较为因素重要性，拟合关系不证明因果。合成数据验证只证明工程流程。预测未来生长还需要预测日期及当时能获得的因素；当前保留方案支持给定因素条件下的预测，日期留出不证明任意提前量或未见地块上的准确性。

## 当前可采用的八个方案

| 方案 | 候选因素 | 实测训练目标 |
| --- | --- | --- |
| 多因素作物生长指标预测 | 冠层覆盖度、块茎干物质；可按合同调整 | 叶面积指数、地上生物量 |
| 土壤与天气条件下的叶面积指数预测 | 日均温、日辐射、降雨、土壤黏粒和有机碳 | 叶面积指数 |
| 土壤与天气条件下的地上生物量预测 | 日均温、日辐射、降雨、土壤 pH 和容重 | 地上生物量 |
| 土壤与天气条件下的冠层覆盖度和叶面积联合预测 | 日均温、日辐射、降雨、土壤有机碳和黏粒 | 冠层覆盖度、叶面积指数 |
| 土壤、气象与卫星植被指数联合预测 | 准确红光/近红外计算的 NDVI、土壤和气象 | 叶面积指数 |
| 地上生物量生长曲线 | 平台从实测记录提取的观测日期 | 地上生物量 |
| 冠层与天气条件下的块茎干物质预测 | 冠层覆盖度、日均温、日辐射、降雨 | 块茎干物质 |
| 卫星植被指数辅助地上生物量预测 | 准确红光/近红外计算的 NDVI、土壤和气象 | 地上生物量 |

保留方案均输出训练后的模型和预测表，计算逐目标留出误差。新数据和真实取数资格仍须在应用及执行时检查，不能凭目录可见就认为数据已经取得。静态土壤因素需要多个地块中足够的独立差异；输入不可辨识时拒绝拟合。

## 下架及接口兼容

首轮筛选从 20 个主题中保留 5 个，另关闭 2 个隐藏分析替代方法的默认入口。本轮沿用同一资格新增 3 份有独立训练目标和预测流程的方案，新增方案在训练时按观测日期切分验证资料。只做统计、天气阈值分析、固定案例、既有模拟结果展示，或未交付自有采集与模型复用闭环的方案暂不提供新建入口。

- 业务与工作区 `GET /study-templates` 共用研究资格，只列可采用的训练方案。
- 已撤下方案的默认 `GET /study-templates/{id}` 返回 404；页面应提示选择现有目录。
- 已保存方案继续按 `layout.study_template.id` 和准确 `sha256` 查询历史详情。不能去掉摘要改取最新定义。历史读回、原版本运行及模型引用保持。
- 组件目录与历史组件合同继续保留。描述统计、天气条件和模拟分析可以是已有研究的步骤，但不作为本目录中的独立训练预测研究。
- 统一 `inspection`、保存和发布合同继续使用。模型关系展示读取已保存模型的真实参数，不从名称、示例结果或系数大小推测农业结论。
