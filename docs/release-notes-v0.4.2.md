# v0.4.2 研究模板图标

- 工作区和业务 API 的模板列表及详情统一返回图标名称。`icon_name` 的值 `satellite-canopy-cover` 对应交付文件 `satellite-canopy-cover.svg`。
- 静态资源地址为 `{部署地址}/designer/study-icons/{icon_name}.svg`。跨版本对接时，先去掉名称末尾已有的 `.svg`，再拼接静态资源地址。内置设计器兼容两种响应格式。
- 20 个图标采用同名的合并轮廓版 SVG，每个文件使用一个闭合复合路径。
