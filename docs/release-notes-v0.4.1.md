# v0.4.1 研究目录扩展与模板图标

2026-11-20。公开研究目录从 8 套扩展到 20 套，保留原模板标识及准确摘要。

- 新增 12 套作物生长研究，覆盖日期曲线、表型估测、天气与土壤条件、遥感辅助预测。每套声明实测目标、已知因素、留出评价和可复用模型。
- 每套方案均配置一份 SVG，按 1024 × 1024 画布及闭合填充路径导出，使用圆润实心轮廓。工作区与业务 API 的模板列表和详情新增可选的 `icon_name`，例如 `satellite-canopy-cover.svg`。静态资源位于 `{部署地址}/designer/study-icons/{icon_name}`。
- 第 5 步标题展示所选训练模型。方法弹窗保留与实际输入绑定一致的资料处理说明，例如卫星 NDVI 配对和平台日期换算。
- 数据库沿用迁移 0016。FastAPI 文档版本与安装包版本同步。
