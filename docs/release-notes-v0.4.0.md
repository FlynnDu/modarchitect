# v0.4.0 作物生长研究与统一计算配置

2026-11-20。研究目录收录 8 套可配置的作物生长关系与预测方案，围绕指标采集、关系训练、留出验证、模型保存与复用预测组织。

## 改动项

- **八套研究方案。** 涵盖叶面积指数、地上生物量、冠层覆盖度、块茎干物质和生长曲线。新建目录聚焦关系训练和预测。历史模板仍可用准确的 `id` 与 `sha256` 回读，已应用的研究和模型继续引用原正式版本。
- **五种计算方法。** 逻辑斯蒂生长曲线、多变量线性回归、随机森林、XGBoost 与高斯过程使用统一的方法卡片。平台提供默认参数。更换训练模型时保留卫星 NDVI、日期派生等资料处理步骤。WOFOST 与 APSIM 展示为待接入。
- **五步设计。** 「计算与评价」集中展示数据资源、计算配置和评价指标，第 5 步之后直接进入检查与确认。平台资料采集在「研究数据与运行」中使用。
- **可保存的训练策略和指标。** 日期自动划分默认 80% / 20%，可调整训练比例。可选择 R²、RMSE、MAE 与平均偏差。保存后重新打开可核对选择，发布后运行读取封存的比例和指标。配置阶段无需填写训练截止日期。

## 接入与部署

- 方法目录使用 `GET /api/v1/model-center/research-methods`。统一检查响应通过 `inspection.evaluation` 提供划分策略、比例，以及指标选中和必选状态。方案正文在 `evaluation.training_percent` 与 `evaluation.metrics` 保存选择。旧方案缺省时沿用原策略和指标。
- FastAPI 的 Swagger 和 OpenAPI 版本由已安装的发布包提供。可通过 `/openapi.json` 的 `info.version` 核对部署版本。
- 默认请求已撤下的方案模板返回 404。用正式版本开启新草稿后编辑，历史配置和摘要按原版本回读。
- 从 v0.2.2 升级需执行 v0.3.0 的数据库迁移 0016。v0.4.0 在 0016 基础上发布。处理训练任务的执行端需采用本版本逻辑，确保按封存配置切分及评价。
- 运行资格由注册制品、数据来源、观测覆盖和运行前校验共同决定。日期留出和合成数据验收适用于配置及流程验证，真实农业预测精度须用独立实测验证。
