# 按研究问题选择方案

研究人员先明确要回答的问题，再决定研究对象、日期、指标、数据与方法。每个方案说明需要什么资料、会得到什么结果，以及结论能够解释到什么程度。

[进入研究方案库](http://192.168.3.249:18925/designer/#select)。

## 使用平台天气与土壤资料

1. 从指标库选择研究目标和因素。天气使用系统指定来源；土壤还需选择标准土层与均值。实测训练目标仍须来自对应人工记录。
2. 在“数据来源”载入自有观测，填写对象、日期和人工指标。第三方列可留空，也可以只载入实测列，采集后会补齐。
3. 填写研究参考点的纬度、经度，点击“采集所选平台指标”。系统按观测的对象与日期保存采集任务，取得并核验后采用资料；平台数值只读。
4. 保存、检查并运行研究，完成训练后保存模型。预测新日期前，载入新日期所需因素记录并重新采集平台资料；预测复用已有训练状态。

当前入口支持一个地块种植季的参考位置；这不产生企业地块权限。土壤是静态网格估计，不是当日墒情。历史资料用于回溯或给定因素研究，不能当作在过去预测时已经知道的未来信息。合成示例不能通过采集自动变成实测研究。资料缺失或不满足要求时保留原数据并说明失败。

## 独立开展的九项田间与环境研究

| 研究主题 | 要回答的问题 | 所需资料 | 得到的结果 |
|---|---|---|---|
| 低温与霜冻条件 | 近期是否出现需要田间核查的低温条件？ | 逐日最低温及来源质量 | 条件识别、有效日覆盖与解释范围 |
| 高温条件 | 近期高温达到什么程度？ | 逐日最高温及来源质量 | 高温条件与资料覆盖 |
| 降雨不足与水分供应 | 降雨是否不足，是否需要补充墒情观测？ | 完整日期窗口的降雨资料 | 少雨条件与需补充的证据 |
| 强降雨与积水条件 | 是否达到需要检查排水、积水的条件？ | 逐日降雨资料 | 多雨条件与核查范围 |
| 温湿条件与病害风险 | 温湿环境是否满足病害气象筛查要求？ | 同期温度、降雨、饱和水汽压差 | 条件信号及后续观测需要 |
| 耕层土壤理化特征 | 已有土壤资料说明哪些特征，覆盖哪个土层？ | 同来源、同深度的土壤属性 | 属性汇总与数据支撑范围 |
| 植被指数时序变化 | 不同日期的植被指数如何变化？ | 同范围、质量合格的指数成果 | 日期对比、变化量与样本不足提示 |
| 生长与水分限制 | 已有模拟中的水分、冠层与生物量如何共同变化？ | 同一模型情景的逐日指标 | 过程指标、变化量与同日关系 |
| 产量形成与干物质积累 | 储藏器官和地上干物质如何随发育阶段积累？ | 同一情景的干物质与物候指标 | 积累过程与指标关系 |

这些研究分别使用自己的数据和计算方法，可以独立保存、调整范围并运行。开展某一项研究不需要先完成全部勘察。

## 其他研究主题

方案库还提供多因素作物生长指标预测、生长趋势与环境因素联合预测、田间观测汇总、温室耗水估算与称重对照，以及三种冠层温度研究：环境关系、短期时序预测和空间分布预测。

冠层温度关系研究可选择随机森林、XGBoost 或高斯过程。时序和网格时序使用相应的数据形态。方法选择围绕研究问题，不要求研究人员先认识所有计算组件。

## 使用步骤

1. 选择研究主题，点击“查看研究流程”，了解数据如何进入分析并产生结果。
2. 点击“使用这个方案”，保存到自己的研究工作区。
3. 核对数据与研究对象的关系。方案会单独标明当前载入的是示例资料、估计结果、模拟结果还是实测记录。
4. 调整允许的研究日期、作物或已有指标。系统不会因为改参数而更换数据来源。
5. 检查后运行，查看结果、数据覆盖和结论适用范围。保存的研究可以重新打开。

当前提供的示例数据可以直接运行，用于了解方法与操作。实际地块研究应采用对应对象、单位和来源的资料；数据来源是否已可使用，以系统中的实际状态为准。

流程卡片直接列指标、单位、方法参数、记录数量和实际成果，长说明收在明细中。已接入的时间留出预测研究按“研究输入、数据集、模型训练、预测成果、时间留出评价”展示，留出实测沿虚线直接进入评价，与模型预测值对照。分析等其他研究继续按其实际方法与成果展示。宽屏可横向滚动，窄屏纵向阅读；展开“模型连接关系”可查看组件依赖。运行记录使用当时的方案，修改当前设置后不会沿用上次运行的成果状态。

“生长趋势与环境因素联合预测”的五项外部指标是定植后天数、株高、NDVI、土壤体积含水率和气温，它们放在同一张观测表中；表数不是指标数。默认示例 90 条记录包含 45 条历史拟合、25 条后续回归训练和 20 条时间留出，修改截止日期后按实际记录重新计数。上游产生的历史趋势估计不需要手动录入，后续预测只需四项已知输入。当前是时间留出评价，尚未接入独立地块验证。

输入调整包含新增、删除和替换记录，以及增删因素和目标；允许范围以当前方案为准。指定资料方案只能调整已开放的日期、作物或分析指标。系统在启动前检查来源、数据与模型设置，不满足条件时说明原因并阻止提交。完整约束见[研究平台规则](platform-rules.md)。

## 如何理解结果

- 气象条件达到筛查要求，并不等于已经发生灾损、积水或病害。
- 资料不完整时，不能把“无法判断”解释成“没有风险”。一般条件规则也不等于已按品种和生育阶段完成校准。
- 土壤网格参考值不等于田间实测；没有依据时不输出作物适宜性分数。
- 两期影像可以比较变化，不能仅凭两期数据训练可靠的生长预测模型。
- 生长模拟与干物质过程保留其模拟性质；储藏器官干物质不等于实际收获鲜产量，同日相关也不代表因果关系。
- 多因素生长预测和历史趋势联合预测可以保存候选模型，并在新输入上继续预测。冠层温度方法当前提供独立留出评价，其评价报告不能当作可继续调用的模型。
